# ЭкоСорт — Android APK project

Это Android-проект, который открывает предоставленный HTML-файл внутри отдельного Android-приложения (WebView), а не в Chrome.

## Что уже подключено
- Ваш исходный `index.html` без изменения карточек, игры, привычек и счёта.
- Отдельное имя приложения: **ЭкоСорт**.
- Отдельная иконка.
- JavaScript и localStorage включены, поэтому сохранение прогресса внутри приложения поддерживается.
- Минимальная версия Android: 6.0 (API 23).

## Как получить APK через GitHub Actions
1. Создайте новый пустой репозиторий на GitHub.
2. Распакуйте архив и загрузите ВСЕ файлы и папки проекта в репозиторий.
3. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
4. Запустите workflow **Build EcoSort APK** (Run workflow) или сделайте commit в ветку `main`.
5. Когда сборка завершится успешно, откройте её запуск и скачайте artifact **EcoSort-APK**.
6. Распакуйте скачанный artifact. Внутри будет `app-debug.apk`.
7. Передайте APK друзьям. На Android при установке может потребоваться разрешить установку приложений из выбранного источника.

## Важно
- Это debug APK для установки и тестирования, не публикационная подписанная версия для Google Play.
- Прогресс хранится локально на каждом устройстве отдельно. Он не синхронизируется между телефонами.
- Если проект использует внешние интернет-ресурсы, им по-прежнему понадобится интернет.
